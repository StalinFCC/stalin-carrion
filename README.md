## Publicación
Este repositorio está preparado para GitHub Pages. `index.html` debe permanecer en la raíz.

## Antes de publicar
1. Edita `config.js` y añade tu usuario de GitHub, vídeos, demos y repositorios reales.
2. Sustituye las visuales provisionales de Física/Matemáticas y Jomara por capturas originales cuando las tengas.
3. Revisa el CV de `assets/cv/` y actualiza ubicación o datos si fuese necesario.
4. Publica únicamente material y código que tengas permiso para compartir.
